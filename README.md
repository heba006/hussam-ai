# Hussam-Ai ✦ منصة مبيعات اشتراكات تطبيقات الذكاء الاصطناعي

منصة عربية (RTL) جاهزة للتشغيل، تتيح لك عرض تطبيقات الذكاء الاصطناعي التي تبيع اشتراكاتها، تعديل أسعارها، إضافة تطبيقات جديدة أو حذفها، وربط المنصة برقم واتساب واحد يتم تعديله متى شئت — مع سلة مشتريات وعدّاد زوار حقيقي.

---

## المزايا

| الميزة | التفاصيل |
|---|---|
| عرض التطبيقات | بطاقات أنيقة لكل تطبيق: الاسم، الشركة، الوصف، المزايا، السعر، شارة مميزة، وصورة أصلية للتطبيق |
| إدارة كاملة | إضافة / تعديل / حذف تطبيق، إخفاء تطبيق مؤقتاً بدل حذفه |
| الكمية | كمية متاحة لكل اشتراك تظهر للزائر وتُخصم تلقائياً عند كل طلب، ويتوقف البيع عند نفادها |
| العروض | قسم «العروض» مستقل في الصفحة + فلتر، مع نص عرض خاص لكل تطبيق |
| قسم الألعاب | قسم مستقل `#games` لشحن الألعاب (فري فاي، ببجي، روبلكس، روكيت ليغ، متابعين…) — أضف باقات من لوحة التحكم باختيار الفئة «ألعاب» |
| صور التطبيقات | رفع صورة من الجهاز أو إضافة رابط، تظهر أعلى بطاقة التطبيق |
| المساعد الآلي | مساعد داخل المنصة يرد فوراً على الزوار بالأسعار والعروض والمزايا وطريقة الاشتراك |
| السعر | تعديل السعر وسعر «قبل الخصم» في أي وقت |
| واتساب | رقم واحد في الإعدادات، وكل أزرار التواصل ورسائل الطلب تُبنى تلقائياً |
| السلة | إضافة، تعديل الكمية حسب المتوفر، حذف، حساب الإجمالي، ثم إتمام الطلب عبر واتساب برسالة جاهزة |
| عدّاد الزوار | عدّاد حقيقي على الخادم (زيارات + زوار فريدون)، ويمكن تصفيره من اللوحة |
| الطلبات | كل طلب يُسجَّل في لوحة التحكم مع التفاصيل والإجمالي |
| لوحة تحكم | محمية بكلمة مرور، مع إحصاءات وجلسة مشفّرة |
| التصميم | Glassmorphism + تدرجات Aurora، وضع فاتح/داكن تلقائي، خطوط عربية احترافية |
| الاستجابة | متوافق مع الجوال والتابلت وسطح المكتب، مع مراعاة تقليل الحركة |

## التشغيل السريع

```bash
# 1) شغّل الخادم (لا يحتاج أي تثبيت حزم)
npm start
# أو
node server.js
```

على Windows يمكنك أيضاً **النقر مرتين على `start.bat`** — سيشغّل المنصة ويفتح المتصفح تلقائياً.

ثم افتح: **http://localhost:3000**

### كلمة مرور لوحة التحكم الافتراضية

```
Hussam@2026
```

> **غيّرها فوراً** من: لوحة التحكم ← الإعدادات ← كلمة المرور. كما يُنصح بتغيير رقم واتساب من نفس الصفحة.

لضبط كلمة المرور الأولى عبر متغيّر بيئة (قبل إنشاء ملف البيانات فقط):

```bash
set ADMIN_PASSWORD=MyStrongPass123   # على Windows CMD
$env:ADMIN_PASSWORD="MyStrongPass123" # على PowerShell
node server.js
```

لتغيير المنفذ:

```bash
set PORT=8080
node server.js
```

## من أين أعدّل كل شيء؟

افتح الموقع ← زر **درع الأمان** في الترويسة (أو «لوحة التحكم» في التذييل) ← أدخل كلمة المرور.

### التطبيقات
- **إضافة تطبيق**: زر «إضافة تطبيق»، ثم املأ الاسم والسعر والوصف والمزايا والأيقونة واللون.
- **تعديل السعر**: زر القلم بجانب التطبيق.
- **حذف تطبيق**: زر سلة المهملات (يُحذف نهائياً من المتجر).
- **إخفاء مؤقت**: افتح التطبيق وأزل علامة «معروض في المتجر».

### الكمية والمخزون
- في نموذج التطبيق: حقل **«الكمية المتاحة»** (0 – 9999).
- تظهر الكمية على بطاقة التطبيق بشريط صغير: أخضر (متوفر)، أصفر (3 أو أقل — كمية محدودة)، أحمر (نفدت الكمية).
- عند وصولها إلى 0 يتوقف زر «أضف إلى السلة» ويظهر «نفدت الكمية»، ويبقى زر واتساب للاستفسار.
- كل طلب مُسجَّل يخصم الكمية تلقائياً على الخادم، والسلة لا تسمح بطلب أكثر من المتوفر.
- تظهر الكمية الحالية أيضاً أمام كل تطبيق في تبويب «التطبيقات» داخل اللوحة.

### العروض
- فعّل خيار **«أضف إلى قسم العروض»** في نموذج التطبيق، واكتب **نص العرض** (مثال: «خصم 20% لأول 12 مشترك»).
- يمكن أيضاً اختيار الفئة «العروض» من قائمة الفئة، وسيُعتبر التطبيق عرضاً تلقائياً.
- يظهر قسم «العروض» في الصفحة الرئيسية (ورابطه في الترويسة)، وفلتر «العروض» أعلى شبكة التطبيقات.

### صور التطبيقات
- من نموذج التطبيق: **«صورة التطبيق الأصلي»** ← «اختيار صورة» (PNG / JPG / WEBP / GIF، حتى 5 ميجابايت).
- أو ألصق رابط صورة مباشر يبدأ بـ `https://` واضغط Enter.
- زر «إزالة» يحذف الصورة، وتُحذف الصورة القديمة تلقائياً من `public/uploads` عند استبدالها أو حذف التطبيق.
- إن لم تضع صورة، تُستخدم أيقونة التطبيق كما هي.

### المساعد الآلي
- يعمل داخل المنصة (زر «مساعد Hussam-Ai» أسفل الشاشة) ويجيب على الأسئلة الشائعة فوراً: الأسعار، العروض، مزايا كل تطبيق، طريقة الاشتراك، والتواصل عبر واتساب.
- بياناته تؤخذ مباشرة من تطبيقاتك: أي تعديل في السعر أو الكمية أو العروض ينعكس في ردوده.
- للتحكم به: الإعدادات ← «تفعيل المساعد الآلي داخل المنصة»، ويمكن كتابة **رسالة الترحيب** التي تظهر عند أول فتح (اتركها فارغة لاستخدام النص الافتراضي).
- بعد ظهور فقاعة تنبيه للزائر، يمكنه فتح المحادثة والاختيار من الأزرار السريعة أو كتابة سؤاله.

### رقم واتساب
- الإعدادات ← «رقم واتساب» ← أدخل الرقم مع رمز الدولة وبدون `+` أو مسافات.
- مثال: `966500000000`.
- كل أزرار «اطلب عبر واتساب» ورسالة السلة ستستخدم الرقم الجديد مباشرة.

### عدّاد الزوار
- يعمل على الخادم: كل زيارة تُحتسب مرة واحدة لكل جلسة متصفح، والزوار الفريدون يُحتسبون مرة واحدة لكل جهاز.
- يُحفظ العدد في `data/store.json` ولا يضيع عند إعادة التشغيل.
- لتصفيره: الإعدادات ← «تصفير عدّاد الزوار».

## الطلبات عبر واتساب — كيف تعمل؟

1. الزائر يضيف اشتراكات إلى السلة.
2. يضغط «إتمام الطلب عبر واتساب».
3. يُسجَّل الطلب في لوحة التحكم (تبويب «الطلبات») وتُخصم الكميات من المخزون فوراً.
4. تُفتح محادثة واتساب برسالة جاهزة تحتوي أسماء التطبيقات والكميات والإجمالي والاسم والملاحظة.
5. الزائر يرسل الرسالة، وتكمل أنت التسليم.

> إن تعذّر الوصول إلى الخادم، سيُفتح واتساب على أي حال حتى لا تخسر العميل، مع تنبيه بسيط.

## النشر على الإنترنت

المنصة تعمل على أي استضافة تدعم **Node.js 18+** (VPS، Railway، Render، Fly.io، Plesk…):

```bash
npm start
```

نقاط مهمة:
- اجعل متغيّر البيئة `PORT` كما تطلبه الاستضافة (الافتراضي 3000).
- استخدم **HTTPS** دائماً.
- احتفظ بنسخة احتياطية من `data/store.json` (يحتوي التطبيقات والأسعار والطلبات والعداد).
- إن أردت البدء من جديد: احذف `data/store.json` وأعد تشغيل الخادم.

### بنية المشروع

```
.
├── server.js            # الخادم + واجهة API (بدون حزم خارجية)
├── package.json
├── data/
│   └── store.json       # يُنشأ تلقائياً: التطبيقات، الإعدادات، الطلبات، العداد
└── public/
    ├── index.html       # الصفحة الرئيسية + لوحة التحكم (RTL)
    ├── styles.css       # نظام التصميم الكامل
    ├── app.js           # السلة، الواجهة، إدارة اللوحة، المساعد الآلي
    ├── uploads/         # صور التطبيقات المرفوعة من اللوحة
    └── favicon.svg
```

## ملاحظات أمنية

- كلمة المرور تُخزَّن مشفّرة (scrypt) وليست نصاً صريحاً.
- جلسة اللوحة عبر توكن موقّع (HMAC) ينتهي بعد 8 ساعات.
- محاولات الدخول محدودة (8 محاولات ثم حظر 10 دقائق).
- كل المدخلات تُعقَّم على الخادم قبل الحفظ، والأسعار تُحسب من الخادم عند تسجيل الطلب.
- غيّر كلمة المرور الافتراضية قبل النشر، ولا تشارك رابط اللوحة مع كلمة المرور.

## واجهة API مختصرة

| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/api/public` | بيانات المتجر العامة (التطبيقات + الإعدادات + الإحصاءات) |
| POST | `/api/visit` | تسجيل زيارة وتحديث العدّاد |
| POST | `/api/orders` | تسجيل طلب جديد |
| POST | `/api/admin/login` | تسجيل دخول المشرف |
| GET | `/api/admin/data` | كل البيانات (يتطلب توكن) |
| POST | `/api/admin/apps` | إضافة تطبيق |
| PUT | `/api/admin/apps/:id` | تعديل تطبيق |
| DELETE | `/api/admin/apps/:id` | حذف تطبيق |
| PATCH | `/api/admin/settings` | تعديل الإعدادات ورقم واتساب وإعدادات المساعد |
| POST | `/api/admin/upload` | رفع صورة تطبيق (Data URL) ← يرجع `/uploads/...` |
| POST | `/api/admin/password` | تغيير كلمة المرور |
| POST | `/api/admin/stats/reset` | تصفير العدّاد |
| DELETE | `/api/admin/orders/:id` | حذف طلب من السجل |
